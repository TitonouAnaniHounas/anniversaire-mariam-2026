# Pour Mariam 💝

Album d’anniversaire créé par Hounas pour Mariko Mariam, le 10 octobre.

Site statique responsive, sans compilation. Ouvrir index.html ou servir le dossier avec un serveur HTTP local. Les photos et vidéos originales sont conservées dans assets/.

Textes et légendes : app.js. Mise en page : styles.css.

Pour GitHub Pages : publier la branche main, dossier racine. Un dépôt privé exige une offre GitHub compatible (Pro ou supérieure). Le site publié sera accessible publiquement.
